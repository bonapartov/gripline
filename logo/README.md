# Gripline · логотип «Секторы» · SVG

## mark/
Только знак, без надписи, viewBox 64×64.
- gripline-mark-color.svg — цветной, для тёмного фона
- gripline-mark-color-on-light.svg — цветной, приглушённый янтарь для светлого фона
- gripline-mark-mono-light.svg / -mono-dark.svg — монохром

## lockup-horizontal/ · lockup-vertical/
Знак + надпись GRIPLINE. Файлы с суффиксом -plate содержат заливку фона (#111111 или #F0EEE8), без суффикса — прозрачный фон.

## avatar/
512×512, круглая обрезка: тёмный, красный, светлый.

## favicon/
64×64 со скруглением 12px и монохромная версия без плашки.

## Палитра
#E24B4A сектор s1 · #E8A33D сектор s2 (на светлом #C98420) · #F0EEE8 сектор s3 и стрелка · #111111 фон

## Шрифт надписи
Archivo 700, верхний регистр, трекинг 0.2em (горизонталь) / 0.26em (вертикаль). В SVG надпись — живой текст: перед передачей в типографию переведите её в кривые, иначе на машине без Archivo подставится системный шрифт.

## Правила
Ниже 24px использовать монохром. Знак не поворачивать — стрелка всегда вверх. На фото ставить только версию с плашкой или в круге.
