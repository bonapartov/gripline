## Особенности и ограничения

- DQ квалификации №42 Рудько и №81 Тищенко: qual_position и qual_best_lap_ms
  NULL, напечатанные секторы сохранены, но исключаются штатными правилами
  рекордов/идеального круга. Предфинал и финал обоих действительны.
- Отмена отдельных кругов квалификации №98 Толстых не превращена в DQ сессии;
  сохранён опубликованный действительный круг 1:02.675.
- Белов в предфинале классифицирован 20-м с нулём завершённых кругов.
  Сохранены место 20, пустые круг/сектора и только lap=0 в ходе гонки.
  DNS/DNF не выдумывались: в официальном протоколе этих статусов нет.
  Публичный API штатно не показывает его неполную серию предфинала.
- +5 секунд финала у №22, №42, №98, №36 и №81 уже отражены в официальных
  местах. График показывает физические позиции; поле penalty (вычет очков)
  осталось 0, секунды в очки не переносились.
- Очки пропущены по указанию пользователя: points=0 — технический default,
  не подтверждённый итог. Рейтинги/турнирные таблицы/records_cache не пересчитывались.
- Температура группы 19 °C, фактический старт финала 12:52:57.
- По пожеланию пользователя блок протоколов/ссылок не добавлялся, публичные
  документы не создавались; body страницы не менялся. CMS-снимок обновлён
  без сигналов публикации/рассылок, revision 2098.
