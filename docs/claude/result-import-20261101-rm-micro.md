## Очки и аналитика

В исходниках есть только очки предфинала 55/52/50/49/48, а итоговых очков этапа
нет. Пользователь подтвердил, что фотография — официальный протокол финала;
в ней очки также отсутствуют. Итоговые очки не рассчитывались, `points` новых
строк остаётся техническим значением по умолчанию 0. Эти нули не подтверждают
отсутствие начисленных очков. Нужен отдельный итоговый протокол/регламент.

Рейтинг, турнирные таблицы и records_cache не пересчитывались: пользователь
не поручал отдельный пересчёт. Кэш страниц и Пульса очищен после импорта.
