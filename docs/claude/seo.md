## title/description страниц пилота и команды (21.10.2026)

`wagtailseo/meta.html` выводит `<title>`, description, canonical и OG только для Wagtail Page (`self.seo_pagetitle`). У пилота и команды (Django-модели) `<head>` был пустой: Яндекс показывал вместо заголовка URL, в сниппете — текст меню. Теперь вьюха кладёт в контекст `seo` (`website/seo_meta.py::driver_seo`/`team_seo`), `base.html` выводит его инклюдом `includes/seo_meta.html`. Схема по справкам Яндекса/Google: title = имя + одно уточнение (текущий класс у пилота — класс самой свежей гонки; город у команды; у однофамильцев пилота — ещё город) + « | Gripline», **без перечислений** («рейтинг, результаты, фото» — Яндекс прямо называет это плохим шаблоном); цифры (старты/победы/подиумы/титулы, место в рейтинге — только если пилот в таблице) — в description. Имя пилота в шапке — `<h1>`. **Рейтинг** (`rating_seo`): у каждого класса свой title «Рейтинг пилотов картинга — {класс} | Gripline», canonical `?class=ID` (класс по умолчанию — `/top/drivers/` без параметра); класс есть и в `<h1>`, при AJAX-переключении JS обновляет `document.title` и `<h1>`. **Трассы** (`track_seo`): «Название — картинг-трасса[, город, если его нет в названии] | Gripline», в description — адрес, ближайшее соревнование (с названием чемпионата: `EventPage` лежит под `StagePage`, чемпионат — предок), число соревнований и классов с рекордами. **Описания Wagtail-страниц соревнований:** у `EventPage`/`StagePage`/`ChampionshipPage` пустое «Описание для поиска» (вкладка «Продвижение») заменяется собранным из данных (`seo_meta.event_page_description` и др.: этап + класс + чемпионат, дата, трасса, число пилотов и победитель / классы и трассы) — ручное описание в админке всегда главнее. Страницы-списки и обычные страницы заполняются в админке вручную. `templates/wagtailseo/meta.html` — копия шаблона wagtail-seo, чтобы не выводить пустой `twitter:site` (`@`). Без title пока `/compare/`, `/compare-drivers/`, шасси, двигатели — подключаются так же: dict `seo` в контекст. **sitemap.xml** (`website/sitemaps.py`, подключён в `mysite/urls.py` до `coderedcms.urls`): Wagtail-страницы + пилоты (опубликованные, не демо, с хотя бы одним результатом) + команды (опубликованные, с результатами или действующим составом); `lastmod` — конец последнего этапа. Тесты: `website/tests/test_seo_meta.py`.
