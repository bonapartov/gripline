## Страница трассы: классы, секторы, схема 2D/3D, PDF, редактор схемы (23.10.2026)

ТЗ v1.0 и демо — у владельца (`~/Загрузки/gripline_tz_track_page_v1.md`, `gripline_track_page_demo.html`). Страница `/tracks/<slug>/` (`track_detail_view` → `website/services/track_page.py`), шаблон `coderedcms/snippets/track_page.html` + куски `snippets/track/` (панель секторов, статистика, держатель рекорда, карточка этапа), `css/track_page.css`, `js/track_page.js`.

- **Поля трассы** (миграция `0108`): `length_m`, `turns_count` (пусто → число поворотов со схемы, `Track.effective_turns_count`), `scheme_data`/`scheme_svg`/`scheme_updated_at` (пишет только редактор), `scheme_reference` — подложка в закрытом хранилище (`PRIVATE_MEDIA_ROOT`, публичного URL нет). Направление — **существующее `app_direction`** (одно поле для сайта и приложения), отдельного `direction` нет.
- **Расчёты** — `website/services/track_stats.py` (чистые функции над строками `RaceResult`, тесты `test_track_stats.py`). Старт = строка `RaceResult` (в т.ч. `position=0`), победа = `position=1`, подиум 1–3. Рекорд — `min` круга по всем сессиям, при равенстве — более ранний. Секторы — `min` каждого по всем сессиям; «класс без секторов», если ни в одной сессии нет полного S1/S2/S3. Медиана поля — по **последнему этапу класса, где есть секторы** (у пилота — лучший сектор за этап). Сессия с `DQ` в рекорды/секторы не идёт. **Ошибки импорта секторов** (Лемар, финал 7 этапа: S3 = 3.000 и 10.000 при круге 54–55 с → в 3D ~470 км/ч, 24.10.2026) отсекаются: сектор вне 10–80 % круга сессии или сумма трёх вне 90–102 % круга → секторы сессии не берутся; сектор вне 80–150 % медианы этого сектора по классу на трассе → тоже; идеальный круг < 93 % рекорда → у класса «нет секторов». В 3D метка не едет, если средняя скорость сектора по схеме больше порога: 120 км/ч, у классов с «KZ» или «DD2» в названии — 130 (`track_page.max_sector_kmh`, решение владельца 24.10.2026). **Скорость метки:** максимальная на прямой — по классу (`track_page.top_speed_kmh`: Micro 80, Mini 95, Junior 110, Senior 115, DD2 120, KZ 135 км/ч…), сцепление в поворотах 3D подбирает под рекорд (иначе масштаб по секторам разгонял Micro на Лемаре до 120 км/ч). Призрак не показывается, если идеальный круг не быстрее рекорда. Камера «Обзор»/«Сверху» вписывает в окно саму трассу (не подложку), угол не меняется. **«Границы секторов по времени»** в редакторе (`editor_auto_bounds` → `track_scheme.bounds_by_sector_times`, та же модель) ставит S1|S2 и S2|S3 так, чтобы расчётное время секторов делилось как реальное (доли — средние по классам трассы с весом по стартам). Сами записи в БД не правились. «Гонок на сайте» — число прошедших этапов (группировка как у списка «Прошедшие»). **«Гонки по годам»** (24.10.2026): задний приглушённый столбец — все пилоты трассы за год со всех классов (пилот в двух классах — один раз, `track_stats.drivers_by_year`), передний жёлтый — пилоты класса, подпись «класс/трасса»; высота — от максимума по трассе; годы без результатов класса не показываются вовсе (гонки могли быть, протоколов нет), столбцы делят ширину поровну.
- **Переключение класса** — без API: все классы отрендерены сервером в `<template id="glTrPanelTpl<id>">`/`glTrStatsTpl<id>`, JS подставляет; адрес `?class=<id>` (как в рейтинге), canonical без параметра. Порядок кнопок — регламент (`sort_order`), по умолчанию — самый массовый класс.
- **Схема.** Редактор: админка → Трассы → «Редактор схемы» (кнопка в карточке трассы и колонка в списке; `/admin/track-scheme/<id>/`, право `change_track`), `track_scheme_views.py` + `js/track_scheme_editor.js`. Точки линии по направлению движения, старт и границы секторов — доли длины (0…1) от первой точки, повороты, плашки S1–S3, подложка (сдвиг/масштаб/поворот/прозрачность), загрузка линии из **SVG** (берётся только геометрия, файл не сохраняется), проверки резких углов (> 35° между отрезками) и направления (знак площади vs `app_direction`). Предпросмотр «Схема» (SVG с сервера) и «3D» (условный круг). **Сохранение — сразу на сайт** (решение владельца), запись в историю (`log`), сброс кэша страницы (`signals._purge_track_page`).
- **Дополнение №1 к ТЗ (23.10.2026, `~/.claude/uploads/…/gripline_tz_track_page_v1_dop1.md`, образцы «Пластунки» — `website/tests/fixtures/plastunka_scheme_data.json`).** Сглаживание по умолчанию — **центростремительный Catmull-Rom** (`interpolation`), поле — ширина 640, высота по форме трассы 240–480 (`viewBox`, кнопка «Подогнать поле», поворот ±90°/±45° — `rotation_deg`), толщина полотна = `track_width_m` в масштабе (`scale_m_per_unit` из OSM/SVG или длина из карточки), отметки принимаются долей или координатами `*_xy` (допуск 3), номера поворотов — строки до 4 символов, плашки S1–S3 сервер ставит у линии своего сектора (`track_scheme.layout`, редактор берёт их из ответа предпросмотра). Импорт/экспорт JSON, импорт из OpenStreetMap (`.osm`/GeoJSON, `highway=raceway`; файл одной линии без координат (`/api/0.6/way/<id>`) — редактор сам скачивает `/way/<id>/full`, CSP connect-src, проекция в метры, старт — середина длинной прямой, повороты — радиус < 40 м и ≥ 25°) и из SVG (схема Gripline открывается целиком, масштаб — из толщины полотна) — всё в браузере (`track_scheme_editor.js`), на сервер уходят только числа. **Черновик:** пока `provisional` не пуст, на сайте схемы нет (`Track.has_scheme`), кроме галочки «Опубликовать черновик»; в списке трасс — «Схема — черновик». Подпись «© участники OpenStreetMap» — под схемой и в PDF (`source.type == 'osm'`, лицензия ODbL). SVG пересобирается при каждом сохранении трассы (`Track.save`), т.к. толщина зависит от длины.
- **Скрипты админки — только с `defer`**: блок `extra_js` Wagtail выводится в `<head>`, до разметки — без `defer` редактор не запускался (23.10.2026, «нажимаю Сохранить — ничего не происходит»).
- **SVG строит сервер** (`services/track_scheme.py::render_svg`) из проверенных чисел (`clean_scheme_data`) — разметка из браузера в `scheme_svg` не попадает. Сплайн Catmull-Rom → ломаная (20 точек на отрезок); та же геометрия в `js/track_scheme_geom.js` (редактор, 3D) — **менять оба**, `test_js_geometry_matches_python` сверяет через Node.
- **3D** — `js/track_3d.js`, three.js r128 + OrbitControls лежат в `static/website/vendor/three/r128/`, грузятся только по кнопке «3D» (нужны схема + длина + WebGL). Метка — модель карта с пилотом (`js/track_3d_kart.js`, 24.10.2026, вместо кубика; по фото Sodi/CRG/Birel и шлемов Bell/Arai/OMP, раскраска и логотип — canvas-текстуры в цветах Gripline, без внешних файлов), грузится до `track_3d.js` и на странице, и в редакторе схемы. Размер относительно настоящего карта (1,85 м) — общая настройка «Трассы → Настройки страницы» (`TrackPageSettings.kart_scale`, 1–5, по умолчанию 3; сохранение сбрасывает кэш `/tracks/`). Метка проезжает рекордный круг (секторы = лучшие × рекорд/идеальный), призрак — идеальный; призрак по умолчанию выключен (галочка под 3D, решение владельца 24.10.2026). Рисует только при изменениях и на экране; при потере WebGL-контекста пересоздаётся в экономичном режиме.
- **PDF A4** — `/tracks/<slug>/scheme.pdf` (`track_scheme_pdf_view`, WeasyPrint как медиа-киты, `templates/track_scheme/scheme_pdf.html` + `css/track-scheme-print.css`), светлый лист, тёмные цвета секторов, QR. Кэш — Django cache по ключу из содержимого (схема, длина, направление, адрес), `@nocache_page` от wagtailcache.
- **Карта** — JS API Яндекс.Карт 2.1, как на `/pulse/` (у iframe-виджета — рекламные блоки; решение владельца 23.10.2026): метка по координатам, без блока «Открыть в Яндекс Картах», колесо не масштабирует; API грузится, только когда карта близко к экрану (`track_page.js`). Ключ — `settings.YANDEX_MAPS_API_KEY` (тот же, что зашит в `pulse_index_page.html`). «Код карты» (`map_html`) выводится, только если у трассы нет координат. Карта грузится без согласия на cookie — в политике cookie не описана.
