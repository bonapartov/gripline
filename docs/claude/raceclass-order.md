## Порядок классов картинга — регламент вместо алфавита (2026-09-18)

Везде на сайте, где выводится список/фильтр классов (`RaceClass`), сортировка была по алфавиту — `RaceClass.Meta` не задавал `ordering`, вызывающий код добавлял `.order_by('name')`/`sorted(key=lambda x: x.name)` почти в 20 разных местах: `/pulse/`, `/championships/<slug>/`, `/top/drivers/`, `/compare/`, `/compare-drivers/`, `/matrix/` (chassis_track_matrix), weather-impact, tyre-analysis, главная (топ пилотов), страницы трассы/шасси/двигателя/пилота/команды, страница этапа (список участников, мини-таблица протокола), календарь событий (бейджи классов на карточках), ЛК менеджера команды, организаторская панель (список заявок), FastAPI `/classes` (мобильное приложение).

Новое поле `RaceClass.sort_order` (миграции `0041`/`0042`, значения по регламенту дисциплин, шаг кратен 10) + `Meta.ordering = ['sort_order', 'name']` — правится через панель класса в Wagtail-снипете «Классы гонок» (не хардкод). Порядок: Микро → Мини → Мини ГР-3 → Супер-мини → Супер-мини ГР-3 → ОК J → ОК → KZ2 → KZ2 Masters → RM (Micro/Mini/Junior/Senior/DD2/DD2 Masters) → 4Т (Дети/Юноши/Взрослые) → E-10 (БАМБИНИ/МИНИ).

`RaceClass.sort_key_map()` — `{название: sort_order}`, для мест, где группировка уже идёт по строке названия класса (не по объекту `RaceClass`) — агрегаты по пилоту/команде в `driver_detail_view`/`team_detail_view`/`team_ratings_view` (`website/views.py`).

**Отдельный скрытый случай, найденный не сразу:** фильтр-чипы на `/pulse/` рендерятся не из Django-контекста страницы, а клиентским `website/static/js/pulse.js` поверх JSON от `/api/v2/pulse/` (SPA-стиль) — там была своя `.localeCompare('ru')`-сортировка, первый (серверный) фикс её не касался никак, чипы на живой странице остались алфавитными. Добавлен `class_order` (`{имя: sort_order}`) в ответ `pulse_data()` (`website/api.py`), `pulse.js::_classSortValue()` использует его вместо `localeCompare` — и для чипов-фильтра, и для списка чемпионов сезона.

**Сознательно не тронуто:** порядок классов внутри `RaceClassResultGroup` (Wagtail `Orderable` — ручной порядок организатора в админке результатов, задаётся drag-and-drop, никогда не был алфавитным изначально, менять его означало бы отобрать существующую фичу). (Отдельный справочник классов развесовки `KartClass` удалён 12.10.2026 — `/balance/` тоже на `RaceClass`.)
